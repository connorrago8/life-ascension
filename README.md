# LIFE ASCENSION

A mobile-first real-life RPG where character progress reflects real-world actions.

## Current status

Phase 1 development. The full v0.3 application package has been prepared separately; this repository is being initialized. No production deployment or database security validation has been completed.

## Phase 1 priorities

- Passwordless account sign-in
- Quest templates and dated recurring quest instances
- Completion and deferral workflows
- Exactly-once XP awards
- Row-level security and two-user isolation tests
- Fast mobile Daily Mode

## Privacy

This repository is public. Never commit .env.local, credentials, tokens, personal health records, or private quest data. Production data must live in an access-controlled database.

## Intended stack

Next.js, TypeScript, Supabase, Vercel.
