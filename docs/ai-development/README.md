# AI development notes

Read these at the start of every session, in this order, and do not reread the whole repository first.

1. `current-state.md` — authoritative branch, open PRs, and what not to touch.
2. `release-process.md` — the rules that stop a session from touching production.
3. `known-failures.md` — failures already paid for. Do not rediscover them.
4. `development-workflow.md` — the engine and the loop. Then start the task.
5. `testing-guide.md` — only the commands for the files you are about to change.
6. `architecture.md` — when the task crosses quests, XP, companion, or the delve.
7. `handoff.md` — why this packet exists, the Companion 2.0 case study, and the 30-minute test.

`chatgpt-takeover-prompt.md` is the paste-ready prompt. It is not a substitute for the files above once you are inside the repo.

These files contain no secrets, no share tokens, and no personal account data. Environment variables are named, never valued.
